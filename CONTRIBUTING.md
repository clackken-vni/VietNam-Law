# Contributing to VietLex

Thanks for your interest in contributing!

## Process

1. Fork the repository
2. Create a branch: `git checkout -b feature/your-feature`
3. Make your changes: `git commit -m 'feat: description'`
4. Push: `git push origin feature/your-feature`
5. Open a Pull Request

## Commit Convention

| Prefix | Usage |
|--------|-------|
| `feat:` | New feature |
| `fix:` | Bug fix |
| `refactor:` | Code restructuring |
| `docs:` | Documentation |
| `crawler:` | Crawler / data ingestion changes |
| `data:` | Data or seed changes |
| `chore:` | Maintenance, CI, deps |

## Code Style

- TypeScript strict mode
- ESLint + Prettier
- Unit tests for business logic
- English naming for variables/functions; comments may use Vietnamese
